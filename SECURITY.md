# Bezpieczeństwo

To PoC: endpoint nie ma uwierzytelniania ani limitu zapytań, a porty są wystawione tylko na `127.0.0.1`.
Nie wystawiaj go do internetu bez obu zabezpieczeń (szczegóły: README, „Wymagania i ograniczenia”).

Lukę zgłoś prywatnie przez **Security → Report a vulnerability** w tym repozytorium, nie w publicznym issue.
Poprawki trafiają na gałąź `main`; wspierana jest tylko najnowsza wersja.
